## How to Contribute

1. **Open an Issue**  
   First, create a new issue describing the problem or feature you want to work on.

2. **Create a Feature Branch**  
   Create a new branch from `main` with a meaningful name (e.g. `feature/add-login` or `docs/update-readme`).

3. **Make Your Changes**  
   Implement the changes only related to that issue. Keep commits small and atomic.

4. **Submit a Pull Request**  
   Open a PR, link it to the related issue (`Closes #XX`), and provide a clear description of changes.

5. **Address Code Review Comments**  
   Make requested changes, push new commits, and request re-review.

6. **Wait for Approval and Merge**  
   After approval, the PR will be merged (preferably with Squash & Merge).
